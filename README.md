# Sistema analítico BI y Big Data - Clínica Jesús del Norte

Proyecto final del curso Base de Datos Avanzadas y Big Data (2026-2).

## Requisitos
- Windows 11 con WSL2
- Python 3.10
- SQL Server 2022
- MongoDB 7.0
- Power BI Desktop

## Estructura
- data/: datasets (original solo como ficha, procesado y sintético)
- sql/: scripts DDL y consultas
- etl/: scripts de limpieza y seudonimización
- bigdata/: notebooks PySpark y carga a MongoDB
- bi/: dashboard de Power BI
- experiments/: scripts de los experimentos EXP-01 a EXP-03
- results/: logs, métricas y visualizaciones
- docs/: diagramas y diccionario de datos
